# Product Hunt Launch Guide for Herald

## Overview

This guide covers everything needed to launch Herald (multi-tenant auth system, Rust + React) on Product Hunt.

---

## 1. Gallery Images (Screenshots)

### Specifications
- **Dimensions:** 1270 x 760 px (landscape, PNG or JPG)
- **Count:** Minimum 2, maximum 8 images
- **OG Share Image:** 1200 x 630 px
- **Twitter/X Announcement:** 1600 x 900 px

### Herald Screenshot Plan (8 images)
1. Login flow (login page + MFA verification)
2. Admin dashboard overview
3. Multi-tenant architecture visualization
4. Permission / RBAC management interface
5. API documentation
6. Payment integration config (Stripe / WeChat)
7. Rust performance metrics
8. Code integration example (few lines of code)

### Key Principles
- No stock images — show the real product only
- Add short annotations explaining each screen's value
- Make the first 2 images the strongest (gallery won't show without 2)
