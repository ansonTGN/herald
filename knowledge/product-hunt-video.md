# Product Hunt Demo Video Guide

## Specifications
- **Ideal length:** 60-90 seconds, max 2-3 minutes
- **Structure:** Hook → Problem → Solution → Demo → CTA
- **Audio quality matters as much as visuals** (PH official advice)

## Tools

### Screen Recording + Auto-Polish
| Tool | Platform | Price | Best For |
|------|----------|-------|----------|
| Screen Studio | macOS | ~$89 one-time | Best output quality; auto-zoom, smooth cursor, beautiful backgrounds |
| Cap | macOS | Free (open source) | Quick captures and sharing; Loom alternative |
| DemoMe | macOS | - | Designed for indie developers; one-click screen recording polish |
| ScreenStory | macOS | - | Specifically designed for PH launch videos |
| OBS | All platforms | Free | Full-featured recording; manual setup required |

### Interactive Demos (Not Video)
| Tool | Platform | Best For |
|------|----------|----------|
| Arcade | Web | No-code interactive demos; viewers can click through |
| Storylane | Web | No-code interactive product tours with analytics |

## Herald Video Structure (60 seconds)

1. **0-5s Hook:** "How long does it take to build multi-tenant auth from scratch?"
2. **5-15s Problem:** Pain points of building auth yourself (security, multi-tenant complexity, payment integration)
3. **15-40s Demo:** Show the flow — few lines of code integration → login → permission management → payment integration
4. **40-50s Technical:** Rust performance benchmarks + open source highlight
5. **50-60s CTA:** "Get started free" + GitHub link

## PH Official Tips (from producthunt.com/stories)
1. Create high-quality video content to showcase your product
2. Pay attention to audio quality
3. Optimize for engagement — keep it concise
4. Show the product in action, don't just talk about it

## Community Insights
- Screen recordings with polish (zoom, motion effects) work great for tech products
- Loom-style casual recordings also perform well (authenticity over production)
- Interactive demos let viewers explore hands-on — higher engagement for dev tools
- Don't overspend time on video production — the product itself is the star
