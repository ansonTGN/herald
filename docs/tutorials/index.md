# Herald

多租户认证与授权系统。Rust 后端 + React 前端，单体部署，Docker 上线。

## 给谁看

有 Rust 或 React 经验的开发者，刚加入项目的前两周。

## 前置知识

- Rust 基础（能读懂 Axum handler 和 SeaORM 查询）
- React + TypeScript 基础
- Docker 基本操作
