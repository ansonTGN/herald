## 2. 范围界定

### 2.1 包含功能

- ✅ 用户列表展示（分页、筛选）
- ✅ 创建用户（邮箱、密码、昵称、状态、角色分配）
- ✅ 编辑用户（邮箱、昵称、状态）
- ✅ 删除用户（需要二次确认）
- ✅ 重置密码（系统自动生成 16 位随机密码）
- ✅ 用户状态管理（启用/禁用）
- ✅ 个人资料编辑（昵称）
- ✅ 修改个人密码（带密码强度指示器）
- ✅ 用户头像下拉菜单（Profile、Security 入口）

### 2.2 不包含功能 (Out of Scope)

- ❌ **用户批量导入导出** (原因: 优先级较低，后续版本考虑)
- ❌ **用户审计日志** (原因: 需要审计日志系统支持)
- ❌ **用户活动历史** (原因: 需要活动历史系统支持，如登录和操作记录)
- ❌ **用户头像上传** (原因: 前端存储限制，后续版本考虑)
- ✅ **邮箱验证功能** (原因: 后端已实现完整的邮箱验证 API)

### 2.3 依赖项

- ✅ **用户认证系统** (状态: 已实现) - 提供登录和会话管理
- ✅ **权限管理系统** (状态: 已实现) - 提供 RBAC 权限检查
- ✅ **角色系统** (状态: 已实现) - 支持用户角色分配（realm-admin、user）
- ⚠️ **邮件通知系统** (状态: 部分实现) - 密码重置后的邮件通知待完善

## 5. 功能需求

### 3.0 个人资料管理

#### 3.0.1 管理后台用户头像下拉菜单

在管理后台顶部 Header 的用户头像区域添加下拉菜单功能，点击头像后显示以下选项：

**菜单项**:
- **Profile**: 修改个人信息（跳转到 `/{realmId}/profile`）
- **Security**: 修改个人密码和 TOTP 设置（跳转到 `/{realmId}/profile/security`）
- **Logout**: 退出登录（已存在）

**交互说明**:
- 点击头像显示/隐藏下拉菜单
- 点击菜单项外区域关闭下拉菜单
- 选择 "Profile" 跳转到个人资料编辑页面 `/{realmId}/profile`
- 选择 "Security" 跳转到安全设置页面 `/{realmId}/profile/security`
- 选择 "Logout" 清除会话并重定向到登录页

**目的**: 为拥有管理权限的用户提供便捷的个人中心访问入口，无需退出登录即可管理个人资料、密码和 TOTP 设置。

#### 2.2.4 操作列功能

- **Edit**: 编辑用户信息

- **Delete**: 删除用户（需要二次确认）

**注意**: 当前实现未包含 View 查看详情功能，只有 Edit、Reset Password 和 Delete 操作。

#### 2.2.5 重置密码功能

管理员可以重置任意用户的密码。重置后系统自动生成 16 位随机密码并返回给管理员。

**实现要求**:
- 不能手动输入密码
- 密码由后端自动生成
- 密码长度固定 16 位
- 包含大小写字母、数字和特殊字符
- 重置成功后显示新密码（可复制）

**UI 交互**:
1. 点击 "Reset Password" 按钮打开确认对话框
2. 确认后调用 API 重置密码
3. 成功后显示新密码，提供"复制"按钮
4. 提示管理员将新密码安全地传达给用户

### 2.3 创建用户功能

#### 2.3.1 创建用户对话框

使用 Shadcn/ui 的 `Dialog` 组件创建用户表单，包含以下字段：
| Email | string | 是 | 有效的邮箱格式 |
| Password | string | 创建时是 | 最小 6 个字符（编辑时不显示） |
| Nickname | string | 否 | 最大 50 个字符 |
| Status | UserStatus (0|1|2|3) | 是 | 默认为 1 (Normal) |
| Roles | string[] | 是 | 至少选择一个角色（创建时必填） |

**角色选择说明**：
- 创建用户时必须分配至少一个角色
- 使用 Checkbox 组件进行角色选择
- 默认预选 "user" 角色
- Super Admin 可以分配任意角色（realm-admin、user）
- Realm Admin 只能分配 "user" 角色

**注意**:
- 编辑用户时，密码字段不会显示（密码更新功能待实现）
- 编辑用户时，角色分配不可修改（只读显示）
