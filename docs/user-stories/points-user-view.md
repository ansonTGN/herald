# Points User 积分查询用户故事

**角色代码**: PU (Points User)
**角色定义**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)），可以查看个人积分余额和交易历史。

**故事范围**: US-PU-01 ~ US-PU-03
**创建时间**: 2026-03-13
**状态**: Active

---

## 故事 1：查看我的积分余额 [US-PU-01]

**优先级**: P0

**【用户故事】**
**作为**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：查看自己的积分余额和累计统计（包括分类余额）
**从而**：了解当前积分状况

**【验收标准】**

**场景 1：查看个人积分余额（包含分类余额）**
```gherkin
Given 我已登录 realm-1
And 我的用户 ID 是 user-1
And 我的积分账户有余额 5000
And 余额包含：充值积分 3000，会员积分 2000
When 我访问"我的积分"页面
Then 我看到我的积分余额卡片
And 卡片显示：
  | 字段         | 值         |
  | 总余额       | 5000       |
  | 充值积分余额 | 3000       |
  | 会员积分余额 | 2000       |
  | 单位         | points     |
  | 累计充值积分 | 8000       |
  | 累计会员积分 | 5000       |
  | 累计消耗     | 8000       |
  | 账户状态     | active     |
  | 最后更新时间 | 2026-03-13 12:00 |
```

**场景 2：余额实时更新（显示分类变化）**
```gherkin
Given 我已登录
And 我的积分余额是 5000
And 余额包含：充值积分 3000，会员积分 2000
When 我通过第三方应用消耗 100 积分
Then 我的余额卡片立即更新为 4900
And 会员积分余额更新为 1900（优先消费会员积分）
And 充值积分余额保持 3000
And 不需要刷新页面
```

**场景 3：查看账户状态**
```gherkin
Given 我已登录
And 我的积分账户状态是 "frozen"
When 我访问"我的积分"页面
Then 我看到账户状态显示为"已冻结"
And 我无法进行积分消耗操作
```

**场景 4：余额不足提示（显示分类余额）**
```gherkin
Given 我已登录
And 我的积分余额是 50
And 余额包含：充值积分 50，会员积分 0
When 我尝试消耗 100 积分
Then 我看到错误消息："积分不足，当前余额：50（充值积分：50，会员积分：0）"
And 操作未执行
```

**场景 5：查看积分单位说明**
```gherkin
Given 我已登录
When 我访问"我的积分"页面
Then 我看到积分单位为 "points"
And 我看到积分单位的说明："积分是系统的虚拟货币，可用于消耗第三方应用的服务"
```


## 故事 1.5：查看分类积分余额 [US-PU-04]

**优先级**: P0

**【用户故事】**
**作为**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：分别查看充值积分和会员积分的余额和明细
**从而**：了解不同类型积分的使用情况

**【验收标准】**

**场景 1：查看分类余额明细**
```gherkin
Given 我已登录
And 我的总余额是 5000
And 余额包含：充值积分 3000，会员积分 2000
When 我访问"我的积分"页面
Then 我看到两个余额卡片：
  | 充值积分 | 3000 | 长期有效 |
  | 会员积分 | 2000 | 过期时间：2026-04-15 |
And 我可以看到每种积分类型的余额和过期时间
```

**场景 2：查看消费优先级说明**
```gherkin
Given 我已登录
And 我同时拥有充值积分和会员积分
When 我访问"我的积分"页面
Then 我看到消费优先级说明：
  "消费顺序：优先使用会员积分，再使用充值积分"
And 显示当前消费顺序示意图
```

**场景 3：查看即将过期的会员积分**
```gherkin
Given 我已登录
And 我有 2000 会员积分
And 会员积分将在 7 天后过期
When 我访问"我的积分"页面
Then 我看到过期提醒：
  "会员积分将在 7 天后过期（2026-04-15）"
And 提醒用高亮颜色显示
And 我可以点击查看哪些积分即将过期
```

**场景 4：查看积分来源明细**
```gherkin
Given 我已登录
When 我访问"我的积分"页面的"积分来源"标签
Then 我看到积分来源明细：
  | 来源类型 | 来源描述 | 金额 | 剩余 | 过期时间 |
  | 订阅续费 | Pro 套餐月付 | 1000 | 800 | 2026-04-15 |
  | 充值购买 | 充值 1000 积分 | 1000 | 1000 | 长期有效 |
And 我可以按积分类型筛选
And 我可以按过期时间排序
```

## 故事 1.6：积分过期通知 [US-PU-05]

**优先级**: P1

**【用户故事】**
**作为**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：收到会员积分即将过期的通知
**从而**：及时使用积分避免浪费

**【验收标准】**

**场景 1：查看即将过期的积分**
```gherkin
Given 我已登录
And 我有 2000 会员积分
And 会员积分将在 7 天后过期
When 我访问"我的积分"页面
Then 我看到过期提醒横幅：
  "您有 2000 会员积分将在 7 天后过期"
And 提醒包含过期时间：2026-04-15
And 提醒用橙色高亮显示
And 我可以点击查看详情
```

**场景 2：查看积分过期历史**
```gherkin
Given 我已登录
And 我的历史会员积分已过期
When 我访问"我的积分"页面的"交易历史"标签
And 我筛选交易类型为"过期回收"
Then 我看到过期回收记录：
  | 交易时间 | 交易类型 | 金额 | 描述 | 过期时间 |
  | 2026-03-15 | expire_revoke | -1000 | 会员积分过期 | 2026-03-15 |
```

**场景 3：过期前多级提醒**
```gherkin
Given 我已登录
And 我有 2000 会员积分
And 会员积分将在 7 天后过期
When 我访问"我的积分"页面
Then 我看到过期提醒：
  "您有 2000 会员积分将在 7 天后过期（2026-04-15）"
When 3 天后我再访问
Then 我看到更新后的过期提醒：
  "您有 2000 会员积分将在 3 天后过期（2026-04-15）"
When 1 天后我再访问
Then 我看到更新后的过期提醒：
  "您有 2000 会员积分将在明天过期（2026-04-15）"
And 提醒颜色从橙色变为红色（越来越紧急）
```

**场景 4：过期后自动清理**
```gherkin
Given 我已登录
And 我有 2000 会员积分
And 会员积分的过期时间是 2026-04-15
When 系统定时任务在 2026-04-15 01:00 执行
Then 系统自动将 2000 会员积分状态更新为 expired
And 系统创建积分回收记录
And 我的会员积分余额减少 2000
When 我访问"我的积分"页面
Then 我看到过期提醒：
  "您的 2000 会员积分已过期（2026-04-15）"
And 我可以在交易历史中查看过期记录
```

## 故事 2：查看我的交易历史 [US-PU-02]

**优先级**: P1

**【用户故事】**
**作为**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：查看自己的积分交易历史记录
**从而**：追踪积分消耗和充值情况

**【验收标准】**

**场景 1：查看所有交易记录（包含积分类型）**
```gherkin
Given 我已登录
And 我有 30 条积分交易记录
When 我访问"我的积分"页面的"交易历史"标签
Then 我看到我的交易历史列表
And 列表显示每笔交易的详细信息：
  | 交易时间          | 交易类型 | 积分类型 | 金额 | 交易后余额 | 描述 | 来源 |
  | 2026-03-13 12:00 | subscription_renewal | subscription_credit | 1000 | 1000 | 订阅 pro 套餐续费 | sub_xxx |
  | 2026-03-13 12:30 | consume | subscription_credit | -100 | 900 | 调用 AI API | app-001 |
  | 2026-03-13 13:00 | consume | subscription_credit | -50 | 850 | 生成图片 | app-002 |
  | 2026-03-13 14:00 | consume | topup_credit | -200 | 650 | 调用 AI API | app-001 |
```

**场景 2：交易记录按时间倒序排列**
```gherkin
Given 我已登录
And 我有最近 7 天的交易记录
When 我查看交易历史列表
Then 最近的交易显示在列表顶部
And 最旧的交易显示在列表底部
```

**场景 3：查看充值交易详情（包含积分类型）**
```gherkin
Given 我已登录
And 我有充值类型的交易记录
When 我查看一笔充值交易
Then 我看到详细信息：
  | 字段         | 值                          |
  | 交易 ID     | txn-recharge-001             |
  | 交易类型     | 订阅续费                    |
  | 积分类型     | subscription_credit         |
  | 充值金额     | 1000                        |
  | 交易后余额   | 1000                        |
  | 充值来源     | 订阅 pro-monthly 套餐        |
  | 充值时间     | 2026-03-13 12:00:00         |
  | 过期时间     | 2026-04-15 00:00:00         |
  | 订阅 ID     | sub-001                     |
```

**场景 4：查看消耗交易详情**
```gherkin
Given 我已登录
And 我有消耗类型的交易记录
When 我查看一笔消耗交易
Then 我看到详细信息：
  | 字段         | 值                          |
  | 交易 ID     | txn-consume-001              |
  | 交易类型     | 消耗                        |
  | 消耗金额     | 100                         |
  | 交易后余额   | 900                         |
  | 消耗来源     | AI API 调用                 |
  | 客户端应用   | app-001                     |
  | 消耗时间     | 2026-03-13 12:30:00         |
```

**场景 5：分页查看交易历史**
```gherkin
Given 我已登录
And 我有 100 条交易记录
When 我查看交易历史（每页 20 条）
Then 我看到第 1 页的 20 条交易
And 可以翻页查看其他交易
And 页面显示总交易数："共 100 条交易"
And 页面显示当前页码："第 1 页，共 5 页"
```

**场景 6：导出交易历史**
```gherkin
Given 我已登录
And 我有交易记录
When 我点击"导出"按钮
Then 系统生成交易历史文件
And 文件包含所有交易记录
And 我可以下载该文件
And 文件格式为 CSV 或 Excel
```


## 故事 3：筛选交易记录 [US-PU-03]

**优先级**: P2

**【用户故事】**
**作为**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：按时间范围和交易类型筛选交易记录
**从而**：快速找到特定交易

**【验收标准】**

**场景 1：按交易类型筛选（充值）**
```gherkin
Given 我已登录
And 我有充值和消耗两种类型的交易记录
When 我选择筛选条件"交易类型：充值"
Then 我只看到充值类型的交易记录
And 消耗类型的交易不显示
And 列表标题显示："充值交易记录"
```

**场景 2：按交易类型筛选（消耗）**
```gherkin
Given 我已登录
And 我有充值和消耗两种类型的交易记录
When 我选择筛选条件"交易类型：消耗"
Then 我只看到消耗类型的交易记录
And 充值类型的交易不显示
And 列表标题显示："消耗交易记录"
```

**场景 3：按时间范围筛选（最近 7 天）**
```gherkin
Given 我已登录
And 我有跨越多月的交易记录
When 我选择筛选条件"时间范围：最近 7 天"
Then 我只看到最近 7 天内的交易记录
And 7 天之前的交易不显示
And 列表标题显示："最近 7 天的交易记录"
```

**场景 4：按时间范围筛选（自定义日期范围）**
```gherkin
Given 我已登录
And 我有跨越多月的交易记录
When 我选择自定义时间范围："2026-03-01 到 2026-03-31"
Then 我只看到该时间范围内的交易记录
And 范围外的交易不显示
And 列表标题显示："2026-03-01 至 2026-03-31 的交易记录"
```

**场景 5：按交易来源筛选**
```gherkin
Given 我已登录
And 我的积分消耗来自多个 Client App
When 我选择筛选条件"来源：app-001"
Then 我只看到来自 app-001 的消耗交易
And 来自其他来源的交易不显示
And 列表标题显示："来自 app-001 的交易记录"
```

**场景 6：组合筛选条件**
```gherkin
Given 我已登录
And 我有多个类型的交易记录
When 我选择组合筛选条件：
  | 交易类型 | 时间范围     |
  | 消耗     | 最近 7 天    |
Then 我只看到最近 7 天内的消耗交易
And 充值交易不显示
And 7 天之前的消耗交易不显示
```

**场景 7：清除筛选条件**
```gherkin
Given 我已登录
And 我已设置筛选条件
When 我点击"清除筛选"按钮
Then 所有筛选条件被清除
And 我看到所有的交易记录
And 筛选器恢复默认状态
```

**场景 8：筛选结果为空**
```gherkin
Given 我已登录
And 我没有"充值"类型的交易记录
When 我选择筛选条件"交易类型：充值"
Then 我看到提示消息："没有找到符合条件的交易记录"
And 列表为空
```
