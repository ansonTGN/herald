# 多钱包积分分发规则用户故事

> 角色定义以 [统一角色定义](../_roles.md) 为准。

## 用户故事

### 故事 1：为一个购买配置多条积分分发规则 [US-MWGR-001]

**优先级**: P0

**作为**：Realm Admin（详见 [统一角色定义](../_roles.md)）  
**我希望**：为同一个可购买对象配置多条积分分发规则，并让每条规则选择自己的目标积分账户  
**从而**：一次购买可以同时为用户补充不同业务用途、不同有效期或不同额度模型的积分

**场景 1：配置两个目标账户**
```gherkin
Given Realm 中存在积分账户 A 和积分账户 B
And 存在一个已同步的可购买对象
When 管理员为该对象新增两条启用的积分分发规则
And 规则一选择账户 A，规则二选择账户 B
And 管理员保存配置
Then 该对象显示两条独立的积分分发规则
And 每条规则分别显示目标账户、发放量或额度窗口、有效期与启用状态
```

**场景 2：拒绝无目标账户的规则**
```gherkin
Given 管理员正在编辑一个可购买对象
When 管理员新增积分分发规则但未选择目标积分账户
And 管理员尝试保存
Then 系统拒绝保存
And 页面明确标出缺少目标积分账户的规则
And 已保存的规则保持不变
```

**场景 3：纯权益购买不配置积分规则**
```gherkin
Given 一个可购买对象只用于授予角色或记录支付
When 管理员不添加任何积分分发规则并保存
Then 系统允许保存该对象
And 后续购买不会发放积分
And 该对象的非积分权益仍按原规则履约
```

**场景 4：为订阅规则选择现有自动触发阶段**
```gherkin
Given 管理员正在编辑一个自动续期订阅对象
When 管理员为一条积分规则选择首次订阅、续费和订阅升级中的一个或多个触发阶段
And 管理员保存配置
Then 页面显示该规则适用的全部触发阶段
And 后续只有命中这些阶段的订阅事件执行该规则
And 页面不提供管理员主动发放、SDK 主动发放或退款回收作为可配置触发阶段
```

### 故事 2：为注册配置多条积分分发规则 [US-MWGR-002]

**优先级**: P0

**作为**：Realm Admin（详见 [统一角色定义](../_roles.md)）  
**我希望**：为新用户注册配置多条一次性或免费周期积分规则，并为每条规则选择目标积分账户  
**从而**：新用户注册后可以同时获得面向不同应用或业务线的积分

**场景 1：注册同时进入两个账户**
```gherkin
Given Realm 中存在积分账户 A 和积分账户 B
And 管理员已配置两条启用的注册积分规则
And 两条规则分别指向账户 A 和账户 B
When 新用户完成注册
Then 用户在账户 A 和账户 B 中分别获得对应规则定义的积分或免费周期额度
And 两个账户的余额或额度保持独立
```

**场景 2：没有注册规则**
```gherkin
Given Realm 没有启用任何注册积分规则
When 新用户完成注册
Then 用户注册成功
And 系统不创建任何注册积分或免费周期额度
And 系统不选择隐式默认账户
```

**场景 3：目标账户不可用于新发放**
```gherkin
Given 一条启用的注册积分规则指向已被禁用的积分账户
When 新用户完成注册
Then 系统明确记录注册积分分发失败
And 用户不会只收到其余规则的部分积分结果
And 管理员能够看到需要修正规则目标的诊断
```

### 故事 3：一次业务事件完整执行多条积分规则 [US-MWGR-003]

**优先级**: P0

**作为**：Herald 系统（详见 [统一角色定义](../_roles.md)）  
**我希望**：对同一购买、续费或注册事件完整且幂等地执行全部启用的积分规则  
**从而**：用户不会因重复通知、并发处理或单条规则失败而重复到账或只收到部分积分

**场景 1：购买一次触发多条规则**
```gherkin
Given 一个购买对象配置了两条启用的积分分发规则
And 两条规则分别指向不同积分账户
When 支付成功并完成履约
Then 两条规则各生成一条可追踪的发放结果
And 用户在两个目标账户中分别看到对应积分
And 购买结果显示本次产生的全部积分发放
```

**场景 2：重复事件不重复发放**
```gherkin
Given 一个购买或注册事件已经成功执行全部积分规则
When 系统再次收到同一个业务事件
Then 系统返回已存在的规则执行结果
And 任一积分账户都不会重复增加积分
```

**场景 3：任一规则失败时不部分到账**
```gherkin
Given 同一业务事件需要执行两条积分规则
And 其中一条规则因目标账户不可用而无法执行
When 系统处理该业务事件
Then 本次积分分发整体失败并保留重试能力
And 另一条规则也不会留下已到账的部分结果
And 支付事实或用户注册事实不被伪装成失败
```

**场景 4：订阅生命周期按规则回收**
```gherkin
Given 一次订阅发放曾通过两条规则向两个账户授予会员积分或额度
When 发生取消、退款或升级并需要回收旧权益
Then 系统分别定位两条规则产生的积分或额度
And 只回收该订阅事件对应的未使用部分
And 不影响两个账户中的注册积分、充值积分或其他来源积分
```

**场景 5：主动定向发放不自动扇出**
```gherkin
Given Realm 已配置多条自动积分分发规则
When 管理员或第三方应用显式向某个积分账户主动发放积分
Then 积分只进入请求指定的目标账户
And 系统不执行购买、订阅或注册分发规则
```

### 故事 4：查看和停用积分分发规则 [US-MWGR-004]

**优先级**: P1

**作为**：Realm Admin（详见 [统一角色定义](../_roles.md)）  
**我希望**：查看每个购买或注册配置下的全部积分规则，并单独停用不再需要的规则  
**从而**：调整后续积分分发时，不破坏已有用户的积分记录和退款追踪

**场景 1：停用一条规则**
```gherkin
Given 一个购买对象配置了两条启用的积分规则
When 管理员停用其中一条规则并保存
Then 后续业务事件只执行仍启用的规则
And 已停用规则过去产生的积分与交易记录仍可查看
```

**场景 2：规则修改只影响后续触发**
```gherkin
Given 一条积分规则过去已经产生发放记录
When 管理员修改该规则的发放量、额度窗口或有效期
Then 已产生的积分和额度保持原值
And 修改后的配置从后续业务事件开始生效
```
