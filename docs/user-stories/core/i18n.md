# 国际化（i18n）用户故事

> 角色定义见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)

## 用户故事

### 故事 1：切换界面语言 [US-I18N-001]

**优先级**: P0

**【用户故事】**
**作为**：任何已登录或未登录用户（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：能在前端界面切换显示语言（中文/英文）
**从而**：以我熟悉的语言使用系统

**【验收标准】**

> 验收标准只描述用户动作与可见结果，不写 API 路径、数据表、字段变更、技术实现步骤。

**场景 1：通过语言切换器切换语言**
```gherkin
Given 前端界面当前显示为英文
When 用户点击语言切换器并选择"中文"
Then 页面上所有 UI 文本（导航、按钮、标题、提示、表单标签）立即切换为中文
And 后续页面导航保持中文显示
```

**场景 2：语言偏好持久化**
```gherkin
Given 用户已将界面语言切换为中文
When 用户关闭浏览器后重新访问系统
Then 界面仍显示为中文
```

**场景 3：新用户默认语言**
```gherkin
Given 用户首次访问系统，浏览器语言设置为中文
When 系统加载前端界面
Then 界面默认显示为中文
```

**场景 4：浏览器语言回退**
```gherkin
Given 用户首次访问系统，浏览器语言设置为不支持的语种（如法语）
When 系统加载前端界面
Then 界面默认显示为英文
```

### 故事 2：查看翻译后的错误消息 [US-I18N-002]

**优先级**: P0

**【用户故事】**
**作为**：任何用户（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：看到以当前界面语言显示的错误提示信息
**从而**：理解错误原因并采取正确的操作

**【验收标准】**

**场景 1：中文界面下看到中文错误提示**
```gherkin
Given 界面语言为中文
When 用户执行操作失败（如提交表单验证失败、资源未找到、权限不足）
Then 错误提示以中文显示，包含简明的错误描述
```

**场景 2：英文界面下看到英文错误提示**
```gherkin
Given 界面语言为英文
When 用户执行操作失败
Then 错误提示以英文显示
```

### 故事 3：所有 UI 文本完成翻译 [US-I18N-003]

**优先级**: P1

**【用户故事】**
**作为**：任何用户（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：界面上的所有可见文本都以我选择的语言显示
**从而**：不会看到混杂语言的情况，获得完整一致的使用体验

**【验收标准】**

**场景 1：管理后台全页面翻译一致**
```gherkin
Given 界面语言为中文
And 用户以 Realm Admin 身份登录
When 用户依次访问用户管理、权限管理、客户端应用、积分管理、审计日志等所有管理页面
Then 所有页面的导航菜单、页面标题、表格列头、按钮文字、表单标签、空状态提示、确认对话框文本均显示中文
```

**场景 2：登录/注册流程翻译**
```gherkin
Given 界面语言为英文
When 用户访问登录或注册页面
Then 登录/注册表单的所有标签、占位符、按钮、链接和错误提示均显示英文
```

**场景 3：Toast 通知翻译**
```gherkin
Given 界面语言为中文
When 用户执行操作后触发 Toast 通知（如"保存成功"、"删除失败"）
Then Toast 通知文本以中文显示
```
